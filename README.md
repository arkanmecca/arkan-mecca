# رحلة — منظومة التسعير المستقلة 1.0.0

منظومة عربية لتسعير البرامج والغرف والخدمات، وتخصيص العروض والعمولات للشركات، وحفظ تسعيرات إعادة البيع الخاصة بكل شركة.

**حزمة برمجية جاهزة للإعداد على Google Apps Script. لم تُنشر على حساب Google فعلي من هذه المحادثة.**

ابدأ بفتح `START_HERE.html` من الحزمة، أو اقرأ [دليل الإعداد](docs/SETUP_AR.md).

## ما تتضمنه

- واجهة إدارة وواجهة شركات، متجاوبتان مع الهاتف والكمبيوتر.
- اسم مستخدم وكلمة مرور ينشئهما المسؤول؛ لا يحتاج مستخدم الشركة ربط حساب Google.
- صلاحيات مستقلة للموظفين، وتحقق على الخادم لكل طلب.
- أنواع غرف قابلة للتعريف، ومعادلات البرنامج المرجعية، وتسعير الخدمة كوحدة كاملة.
- تسعيرات وقوالب محفوظة، وعروض لها اعتماد ونشر منفصل.
- عمولة لكل شركة أو مجموعة شركات، مع مراجعة الصافي وحماية الاستثناءات من التطبيق الجماعي.
- تسعيرات الشركة وإضافاتها وأرباحها خاصة بحساباتها داخل التطبيق.
- أسعار مصدر محفوظة تاريخياً، وتحديث اختياري مع مراجعة الفرق.
- طباعة / حفظ PDF من المتصفح، وتصدير Excel واستيراد التعريفات بقالب.
- Google Sheets كمخزن بيانات، وحفظ ذري عبر Sheets API، ونسخ احتياطية خاصة على Drive.

## المجلدات

| المسار | المحتوى |
|---|---|
| `dist/gas` | الملفات الجاهزة للنقل إلى مشروع Apps Script |
| `src` | المصدر: الحسابات والصلاحيات والواجهة |
| `gas` | ربط Google Sheets والإعداد والنسخ الاحتياطية |
| `docs` | الإعداد والاستخدام والبنية وتقرير الاختبار |
| `test` | اختبارات الحسابات والصلاحيات ومحوّل Google |
| `scripts` | البناء وبيئة اختبار محلية ببيانات مصطنعة |

## للمطور

يحتاج إعادة البناء Node.js حديثاً وnpm:

```sh
npm ci
npm run build
npm test
```

لا يلزم Node أو تثبيت حزم npm لاستخدام الملفات المبنية داخل `dist/gas`.

`npm run dev` يشغّل بيئة QA محلية فقط، ببيانات مصطنعة تتجدد عند إعادة التشغيل. مسارات `/qa/admin` و`/qa/company` و`/qa/company-b` و`/qa/mobile` تجهّز حالات اختبار واجهة مصرحاً بها محلياً. هذه المسارات والجلسات التجريبية **غير موجودة في حزمة Google Apps Script**، ويُمنع استخدام خادم QA على الإنترنت أو إدخال بيانات عمل حقيقية فيه.

## حدود النسخة

أسعار البرامج بالدينار الليبي وفق المعادلة المرجعية. الخدمات المستقلة تدعم عملة تكلفة وعملة بيع من الدينار الليبي والدولار الأمريكي والريال السعودي. يمكن جمع خدمات بعملات مختلفة في تسعيرة شركة واحدة، وتبقى إجمالياتها منفصلة. راجع [دليل العملات](docs/CURRENCIES_AR.md).

لا تشمل هذه المنظومة المستقلة الحجوزات أو المحاسبة أو الفواتير متعددة الأرصدة؛ وهي لا تعدّل ملفات أركان.

النشر الفعلي واختبار الأذونات والسرعة والتزامن على حساب Google المطلوب لم يُنجز بعد. راجع قائمة قبول التشغيل في دليل الإعداد قبل دعوة الشركات.

مالك ملفات Google ومن يملك وصولاً مباشراً إليها يستطيع قراءة بيانات التخزين؛ خصوصية تسعيرات الشركات هنا مطبقة في واجهة التطبيق وخادمه، وليست تشفيراً يحجبها عن مالك البيانات.
